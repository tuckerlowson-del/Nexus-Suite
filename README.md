# Nexus Suite Website

Official landing page for **Nexus Suite** — the free all-in-one FiveM AI development platform.

## Deploy on Railway

1. Create a new project on [Railway](https://railway.app)
2. Deploy from this folder (or connect a GitHub repo containing these files)
3. Railway will detect the `package.json` and run `npm start`
4. The site will be live on your Railway domain

## Local run

```bash
npm install
npm start
```

Then open http://localhost:3000

## Files

- `index.html` — complete single-page site
- `package.json` — Railway / Node serve config
